# Changelog

## 2026-02-23

- **Form builder – thank you screen**: Thank you screen is always the last question. New questions and inserted components are added before it; it cannot be moved up, duplicated, or deleted. On load, question order is normalized so a single thank-you screen is at the end.
- **Form components**: Removed the "Payment Info" component (cardholder name, billing email, billing address) from the builder component palette.
